# Product documentation

This directory contains the product context, active specification, technology decisions, and deferred ideas.

## Active specification

The active product specification is [v0.1.md](v0.1.md). It is the primary source of truth for product scope and behavior not yet adopted into OpenSpec. Accepted capability specs in `openspec/specs/` own adopted requirements; the active document links to them instead of duplicating their detailed rules. See [OpenSpec workflow](openspec.md) for incremental adoption and conflict handling.

When a new version becomes active, update this section to point to its specification. Keep previous version specifications as historical records unless explicitly asked to remove them.

## Documentation map

- [Active v0.1 specification](v0.1.md) — current behavior, rules, and scope.
- [Product vision](vision.md) — the problem, audience, principles, and roadmap.
- [Technology stack](stack.md) — agreed technologies and architectural boundaries.
- [Database development](database.md) — Supabase configuration and migration workflow.

- [OpenSpec workflow](openspec.md) — planning artifacts, capability ownership, legacy backlog migration, and Codex skills.
- [Review workflow](review.md) — automated checks, AI review, human review, and follow-up commands.
- [Future ideas](ideas.md) — ideas that are outside the active specification.
