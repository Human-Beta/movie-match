# 003 — Supabase and Drizzle setup

## Goal

Підготувати мінімальне й безпечне підключення застосунку до Supabase Postgres та основу для керування схемою через Drizzle.

## Scope / Requirements

- Додати необхідні залежності для Supabase, Drizzle ORM, міграцій і Zod без альтернативних ORM або зайвих backend-фреймворків.
- Додати приклад змінних середовища без реальних секретів і перевіряти потрібні значення через Zod.
- Розділити server-only доступ до Postgres і клієнт Supabase, який надалі використовуватиметься в браузері для Realtime.
- Додати базову конфігурацію Drizzle та команди для створення і застосування міграцій.
- Підготувати порожню або мінімальну структуру для Drizzle schema; продуктову схему кімнат, учасників, раундів і голосів залишити задачі 004.
- Коротко описати локальне налаштування Supabase та роботу з міграціями.

## Acceptance Criteria

- Проєкт запускається з коректно заданими змінними середовища й повідомляє зрозумілу помилку, якщо обов’язкових значень немає.
- Секретний ключ або прямий Postgres connection string не потрапляє в клієнтський bundle.
- Drizzle конфігурація читає підключення з environment і готова до першої міграції.
- Є задокументовані команди для генерації та застосування міграцій.
- Build, typecheck, lint і наявні тести проходять.
- У git не додано жодних реальних секретів.

## Out of Scope

- Проєктування продуктової схеми бази даних і seed-дані фільмів.
- Реалізація кімнат, учасників, голосування або match calculation.
- Налаштування Supabase Auth, Storage, Edge Functions чи інших сервісів, не потрібних v0.1.
- Детальні Realtime subscriptions та політики доступу для конкретних таблиць — вони з’являться разом із відповідною схемою і сценаріями.
- Production deployment на Vercel.

## References / Notes

- Перед виконанням звіритися з `docs/stack.md`, `docs/v0.1.md` і `AGENTS.md`, якщо вони вже існують.
- Supabase Postgres є базою даних; Supabase Realtime — механізмом realtime; Drizzle — єдиним ORM/query layer.
- Не створювати власний окремий backend, якщо цього не вимагає специфікація v0.1.
