# 001 — Project bootstrap

## Goal

Створити мінімальний, готовий до подальшої розробки каркас Movie Match на Next.js без реалізації продуктових сценаріїв.

## Scope / Requirements

- Ініціалізувати застосунок через `pnpm` з актуальною стабільною версією Next.js.
- Використати React, TypeScript, App Router і Tailwind CSS.
- Налаштувати базові команди для локальної розробки, production build, typecheck, lint і форматування.
- Додати ESLint і Prettier із невеликим, несуперечливим набором правил.
- Додати перевірки перед комітом лише якщо вони прості й не сповільнюють роботу: Husky та lint-staged.
- Залишити одну просту стартову сторінку, яка підтверджує, що застосунок запускається.
- Зафіксувати версію Node.js і package manager у репозиторії.
- Додати коректний `.gitignore` без секретів і локальних артефактів.

## Acceptance Criteria

- Залежності встановлюються через `pnpm install`.
- Застосунок запускається локально та показує стартову сторінку.
- Production build, typecheck, lint і перевірка форматування проходять без помилок.
- Pre-commit перевірка, якщо додана, запускається лише для змінених релевантних файлів.
- У репозиторії немає ключів Supabase, бізнес-логіки кімнат або інших функцій MVP.

## Out of Scope

- Підключення Supabase, Drizzle, Realtime або створення схеми бази даних.
- Реалізація TV- та phone-сценаріїв.
- Компонентна бібліотека, складна дизайн-система, CI/CD та deployment.
- Повноцінне тестове покриття.

## References / Notes

- Чинний стек: Next.js, React, TypeScript, Tailwind CSS і `pnpm`.
- Якщо на момент виконання в репозиторії є `docs/stack.md`, `docs/v0.1.md` або `AGENTS.md`, дотримуватися їх.
- Не додавати інструменти «про запас»: задача має створити простий фундамент для маленького v0.1 MVP.
